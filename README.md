# TerminalPlayer

Локальный музыкальный плеер для Android в эстетике терминала: моноширинный шрифт, ASCII-обложки,
сгенерированные из символьной сетки, и круговой ASCII-визуализатор. При этом корпус приложения —
современный тёмный интерфейс: графитовые карточки со скруглениями, тонкие бордеры, один синий
акцент и нижняя сегментированная навигация.

Внутри по-прежнему нет ни одной векторной иконки и ни одного растрового изображения: всё, что
похоже на иллюстрацию, собрано из символов `.:-=+*#%@`, а все действия обозначены глифами
`[=]`, `[@]`, `[*]`, `[#]`, `>`, `<<`, `>>`, `~^~`.

```
┌──────────────────────────────────────────────┐
│ [/] Search local library              [=]    │
│                                              │
│ MY TRACKS                                 (>)│
│ ┌──────────────────────────────────────────┐ │
│ │ ▓▓▓  Echo Chamber              02:32   > │ │
│ │ ░░░  Echoes from the Void      03:10   > │ │
│ │ ▒▒▒  Dust and Shadow           01:50   > │ │
│ └──────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────┐ │
│ │ LOCAL MIX                            (>) │ │
│ │ Offline selection from your files        │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ CATEGORIES                                   │
│ ┌───────────────┐  ┌───────────────┐         │
│ │ [=]        ·· │  │ [@]        ·· │         │
│ │ PLAYLISTS     │  │ ALBUMS        │         │
│ └───────────────┘  └───────────────┘         │
│ ┌───────────────┐  ┌───────────────┐         │
│ │ [*]        ·· │  │ [#]        ·· │         │
│ │ ARTISTS       │  │ FOLDERS       │         │
│ └───────────────┘  └───────────────┘         │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ [#] LIBRARY        ~^~ VISUALIZER        │ │
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

## Что внутри

| Слой | Технология |
|---|---|
| UI | Kotlin + Jetpack Compose (Material3 — только пустая тема, все поверхности свои) |
| Воспроизведение | `androidx.media3:media3-exoplayer` + `media3-session` (MediaSessionService) |
| Библиотека | `MediaStore.Audio` (scoped storage, без чтения путей к файлам) |
| Избранное | `SharedPreferences` (набор MediaStore id) |
| Визуализатор | `android.media.audiofx.Visualizer` (FFT + waveform) → Compose `Canvas` |
| Состояние | `StateFlow` + `ViewModel`, без DI-фреймворка |
| Мин. версия | API 31 (Android 12) |

Версии сборки: AGP 8.13.2, Gradle 8.13, Kotlin 2.2.21, Compose BOM 2025.09.01, Media3 1.8.0,
compileSdk/targetSdk 36, JDK 17.

## Экраны

### 1. LIBRARY (главная)

* **Search bar** — `[/] Search local library`, пока декоративный: строка показывает будущий поиск,
  но не фильтрует список.
* **`[=]`** — раскрывает строку сортировки `SORT: TITLE / ARTIST / LENGTH`. Выбор применяется к
  списку треков и к порядку внутри групп.
* **MY TRACKS** — карточка с тремя первыми треками: ASCII-обложка, название, исполнитель,
  длительность. Тап запускает трек и открывает полный плеер; долгое нажатие добавляет трек в
  избранное. Круглая кнопка `>` открывает полный список библиотеки.
* **LOCAL MIX** — градиентная карточка (единственный градиент в приложении). Запускает всю
  библиотеку в перемешанном порядке; пунктирная круглая кнопка `>` — та же команда.
* **CATEGORIES** — четыре плитки с ASCII-глифами и точечной матрицей: `PLAYLISTS`, `ALBUMS`,
  `ARTISTS`, `FOLDERS`.
* **Bottom nav** — сегментированный переключатель `[#] LIBRARY` / `~^~ VISUALIZER`; активный
  сегмент залит синим. Справа от него — отдельная клавиша `[S]`, открывающая SETTINGS.
* **Mini player** — появляется над нижней навигацией, когда есть текущий трек: обложка, бегущая
  строка названия, play/pause, next и тонкая полоса прогресса. Тап по карточке разворачивает
  полный плеер.

### 2. Коллекции

Все четыре категории рабочие:

| Категория | Источник |
|---|---|
| `PLAYLISTS` | локальное избранное; один плейлист `FAVORITES`, наполняется долгим нажатием на трек |
| `ALBUMS` | группировка по `MediaStore.Audio.Media.ALBUM` |
| `ARTISTS` | группировка по `ARTIST` (`<unknown>` → `UNKNOWN ARTIST`) |
| `FOLDERS` | группировка по `RELATIVE_PATH` из MediaStore |

Экран двухуровневый: список групп → треки выбранной группы. Системный back сначала выходит из
группы, затем из коллекции. Для сгруппированных треков очередь воспроизведения — это сама группа,
поэтому `next` не выпрыгивает в общий список.

### 3. NOW PLAYING

Открывается тапом по треку или мини-плееру.

* крупная ASCII-обложка, сгенерированная детерминированно из id трека (три паттерна: шум, кольца,
  спираль);
* бегущее название, исполнитель, альбом;
* тонкий seek-bar: тап и перетаскивание, плюс `[-10s]` / `[+30s]`;
* транспорт: shuffle, previous, play/pause, next, repeat (`R` → `A` → `1`);
* `[*]` в шапке — добавить/убрать из избранного;
* нижняя строка статуса `ST / SHF / RPT / SES` — id аудиосессии, к которой цепляется визуализатор.

### 4. VISUALIZER

Круговой ASCII-визуализатор на `Canvas` по символьной сетке (44 колонки):

* **внешнее кольцо** — символы `- / | \` по направлению касательной, сэмплируется по длине дуги
  (~0.25 ячейки), поэтому оно непрерывное; радиус «дышит» в такт частоте, которая соответствует
  углу; четыре `+`-засечки превращают кольцо в радарную шкалу;
* **лучи** — 40 лучей из центра (по числу FFT-полос), длина = уровень полосы, символ конца луча
  выбирается по громкости: `.` → `+` → `*` → `#`;
* **peak-маркеры** — `*` на месте затухающего пика;
* **вращающийся сектор** — яркая дуга кольца, которая обходит окружность с постоянной скоростью;
* **центр** — `[ CORE ]`, RMS в процентах и ASCII-индикатор уровня;
* **спектр снизу** — полоса из `#`-столбиков с `*`-вершинами (21 бар на 40 полос);
* **HUD** — `BANDS/FFT/SR/FPS`, `RMS/PK/BASS/SWP`, id сессии и мигающий курсор.

Палитра визуализатора — серый + синий акцент, чтобы он совпадал с новым корпусом приложения.

### 5. SETTINGS

Открывается клавишей `[S]` справа от нижней навигации; системный back возвращает на экран, с
которого настройки были открыты.

* **ЯЗЫК** — `Системный` (следует локали устройства), `Русский`, `English`. Переключение
  мгновенное: строки интерфейса живут в `i18n/AppStrings.kt`, а не в ресурсах, поэтому композиция
  перерисовывается без перезапуска Activity и без остановки воспроизведения.
* **АНИМАЦИИ** — глобальный выключатель появлений разделов, нажатий кнопок и переключения иконок.
* **О ПРИЛОЖЕНИИ** — версия и пара строк о формате.

## Анимации

* **Открытие разделов** — `AnimatedContent` на маршрутах (`ui/MainScreen.kt`), `Reveal`
  (fade + подъём на 18 dp, стаггер 70 мс) для блоков главной и настроек, горизонтальный слайд при
  входе в группу коллекции, раскрытие строки сортировки, выезд мини-плеера.
* **Иконки** — `GlyphButton` / `GlyphPill` / `AsciiButton` пружинно сжимаются при нажатии, глиф
  активной кнопки и пунктирное кольцо `LOCAL MIX` «дышат», `[*]` в трек-строке появляется со
  scale-анимацией, полоса прогресса мини-плеера интерполируется между тиками позиции.
* Всё это выключается одной настройкой: `LocalMotionEnabled` (`ui/motion/Motion.kt`), значение
  сохраняется в `SharedPreferences` через `data/SettingsRepository.kt`.

## Разрешения

| Разрешение | Зачем | Когда спрашивается |
|---|---|---|
| `READ_MEDIA_AUDIO` (API 33+) / `READ_EXTERNAL_STORAGE` (31–32) | список локальных треков | по кнопке `[ GRANT ]` в карточке MY TRACKS |
| `POST_NOTIFICATIONS` | управление воспроизведением из шторки | вместе с доступом к медиатеке |
| `RECORD_AUDIO` | `Visualizer` требует его даже для захвата **своего** аудиосеанса | при открытии вкладки VISUALIZER |
| `FOREGROUND_SERVICE(_MEDIA_PLAYBACK)` | фоновое воспроизведение | без запроса |

`RECORD_AUDIO` не означает прослушку микрофона: `Visualizer` с явным `audioSessionId` обрабатывает
только выходной поток плеера. Аудио никуда не пишется и не отправляется.

## Сборка

### GitHub Actions
В репозитории уже есть workflow `.github/workflows/android.yml`: он ставит JDK 17 и Gradle 8.13,
перегенерирует wrapper, собирает `:app:assembleDebug` и складывает APK в артефакт
`TerminalPlayer-debug`. Достаточно запушить проект и открыть вкладку **Actions** →
последний run → **Artifacts**.

### Локально
```bash
# требуется JDK 17 и Android SDK (platform 36, build-tools 36.x)
./gradlew :app:assembleDebug      # macOS/Linux (при необходимости: chmod +x gradlew)
gradlew.bat :app:assembleDebug    # Windows
```
APK: `app/build/outputs/apk/debug/app-debug.apk`.

В Android Studio: **Open** → папка проекта → дождаться sync (Studio сама подхватит wrapper) → Run.

`local.properties` с `sdk.dir=...` не коммитится — Studio создаёт его сама, для CI он не нужен
(ANDROID_HOME задаёт `setup-android`/runner).

## Настройка внешнего вида

* **Цвета** — `ui/theme/TerminalTheme.kt`: `Ink`, `SurfaceCard`, `Stroke`, `TextPrimary`,
  `TextSecondary`, `Accent`, `MixStart`, `MixEnd` и т.д. Всё плоские константы, кроме градиента
  `LOCAL MIX`.
* **Шрифт** — по умолчанию `FontFamily.Monospace`. Чтобы подключить кастомный терминальный шрифт,
  положите `.ttf` в `res/font/` и замените одну строку:
  ```kotlin
  val mono: FontFamily = FontFamily(Font(R.font.ibm_plex_mono))
  ```
  Важно: `MonoMetrics` и `AsciiVisualizer` используют `Typeface.MONOSPACE`, для полного
  соответствия замените его там же.
* **ASCII-обложки** — `ui/components/AsciiArt.kt`: ramp `" .:-=+*#%@"`, три паттерна и генератор
  шума; `AsciiArtwork(seed = track.id)`.
* **Точечная матрица и декоративный шум** — там же, `DotMatrix`.
* **Поверхности и кнопки** — `ui/components/TerminalSurface.kt` (`TerminalCard`, `GlyphButton`,
  `DashedRingButton`, `GlyphPill`).
* **Язык и анимации** — `i18n/AppStrings.kt` (таблицы EN/RU и `LocalStrings`),
  `data/SettingsRepository.kt` (хранение выбора), `ui/motion/Motion.kt` (`Reveal`, press-scale,
  глобальный `LocalMotionEnabled`). `res/values-ru/strings.xml` содержит только строки, которые
  читает сама Android (канал уведомления).
* **Визуализатор** — `ui/visualizer/VisualizerEngine.kt` (`BAND_COUNT = 40`, attack/release) и
  `AsciiVisualizer.kt` (`TARGET_COLUMNS = 44`, набор символов `DIRECTION_CHARS`).
* **ASCII-элементы** — `core/Ascii.kt` (прогресс-бар, индикатор, время, hex-сессия) и
  `ui/components/AsciiComponents.kt` (бегущая строка, панели ошибок, курсор).

## Известные ограничения

* Поиск по библиотеке пока декоративный: поле показывает будущую функцию и не фильтрует список.
* Библиотека — только MediaStore: файлы, которые система не проиндексировала, не видны.
* Плейлисты ограничены локальным избранным; пользовательских списков и импорта нет.
* Обложки не читаются из тегов принципиально: вместо них генерируются ASCII-обложки.
* `Visualizer` на некоторых прошивках/эмуляторах возвращает ошибку инициализации — экран честно
  покажет `E_VISUALIZER` вместо падения.
* Нет эквалайзера.
* Приложение не подписано релизным ключом: CI собирает debug APK; для release добавьте свой
  keystore.

## Если что-то не собирается

* **`gradlew: Permission denied`** — `chmod +x gradlew` (в CI это делает workflow).
* **`Failed to find target with hash string 'android-36'`** — в SDK Manager не установлена платформа
  36; поставьте `SDK Platform 36` + `Build-Tools 36.x`, либо дайте AGP скачать её (нужен
  принятый `sdkmanager --licenses`).
* **Предупреждение про пару Kotlin X / AGP Y** — это warning, сборка продолжится. Если хочется
  убрать: обновите `kotlin` и/или `agp` в `gradle/libs.versions.toml` (например,
  `kotlin = "2.3.21"` официально поддерживает AGP до 8.13).
* **`E_VISUALIZER` на устройстве** — прошивка не отдаёт `Visualizer` для чужой/неактивной
  аудиосессии. Нажмите `[ RETRY ]` уже во время воспроизведения; если не помогает — устройство
  не поддерживает эффект, остальной плеер работает.
* **Пустая библиотека** — MediaStore не видит файлы: проверьте, что треки проиндексированы
  (`Files`/`Музыка`), и нажмите `[ RESCAN ]` в карточке MY TRACKS.

Подробное описание архитектуры и принятых решений — в [ARCHITECTURE.md](ARCHITECTURE.md).
